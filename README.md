# Claude Plugins by Andrii Naidenko

A [Claude Code](https://code.claude.com/docs) plugin marketplace.

- **[claude-notify-resume](https://github.com/anaidenko/claude-notify-resume)**
  ([npm](https://www.npmjs.com/package/@anaidenko/claude-notify-resume)) —
  desktop notifications that name the conversation they came from, and reopen
  it when clicked.
- **[claude-video-digest](https://github.com/anaidenko/claude-video-digest)**
  ([npm](https://www.npmjs.com/package/@anaidenko/claude-video-digest)) — turns
  any video into a readable digest: timestamped contact sheet, frame-grouped
  transcript, no hallucinated captions on silent tracks.

Each plugin's README covers installing it. To add the marketplace itself:

```bash
claude plugin marketplace add anaidenko/claude-plugins
```
